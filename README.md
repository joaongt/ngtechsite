# NGTech Solutions

Código do [site da NGTech Solutions](https://www.ngtechsolutions.com.br). A versão atual está em `dist/` e usa HTML, CSS e JavaScript sem etapa de compilação.

Para testar localmente, execute na raiz do repositório:

```sh
python3 -m http.server 8000 --directory dist
```

Abra [localhost:8000](http://localhost:8000/). Para hospedar esta versão em outro serviço, use `dist/` como raiz do site. O formulário de Consultoria depende do Google Forms.

O portfólio inclui NeuroArte, Casa Hernandes e Coleiras Amorosas. Os arquivos anteriores na raiz foram mantidos como referência. Alterações neste repositório não são publicadas automaticamente no domínio da NGTech.
