# NGTech Solutions

Código do [site da NGTech Solutions](https://www.ngtechsolutions.com.br). O site usa HTML, CSS e JavaScript sem etapa de compilação.

Para testar, abra esta pasta no VS Code e clique em **Go Live** na barra inferior (extensão Live Server). O site abre em [localhost:5500](http://localhost:5500/) e recarrega sozinho a cada alteração.

Arquivos principais: `style.css` (base), `design.css` (camada visual e animações), `ui.js` (recursos de todas as páginas), `home.js` (painel, teste de desconto e guia da home) e `calc.js` (calculadora da página de planilhas).

O portfólio inclui NeuroArte, Casa Hernandes e Coleiras Amorosas. Alterações neste repositório não são publicadas automaticamente no domínio da NGTech.
