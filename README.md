# NGTech Solutions

Código do [site da NGTech Solutions](https://www.ngtechsolutions.com.br). O site usa HTML, CSS e JavaScript sem etapa de compilação.

Para testar, execute na raiz do repositório:

```sh
python3 -m http.server 8000
```

Abra [localhost:8000](http://localhost:8000/). Para hospedar o site, use a raiz do repositório. O formulário de Consultoria depende do Google Forms.

O portfólio inclui NeuroArte, Casa Hernandes e Coleiras Amorosas. Alterações neste repositório não são publicadas automaticamente no domínio da NGTech.
